Lifetime Profitability Calculator — a single-file HTML/JS tool that models a loan's full lifetime P&L from disbursement to closure: income, costs, credit risk, and variable profit, with RoA metrics, waterfall charts, EMI/cash-flow schedules, and one-click PDF/Excel export.
	
PRISM is a self-contained, browser-based financial planning and reporting workbook built for a multi-channel lending business. It pulls together monthly actuals, plan/forecast data, and operating KPIs from disconnected sources into a single consistent structure — standardizing channel-level and consolidated profitability, actual-vs-plan variance, and recurring management reporting.Includes modules for Business P&L, Variable P&L, YTD Dashboard, KPI/OKR dashboards, Balance Sheet summary, GL mapping, funding schedules, and a presentation view for leadership reporting.
